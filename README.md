# Email Bridge Bot

**Версия: 0.1.0-rc.2**

Веб-панель и три фоновых компонента для мониторинга почты по IMAP и доставки уведомлений в Telegram и MAX.

## Возможности RC

- Веб-панель на русском языке: настройки, правила, контакты, исключения отправителей и история доставок.
- Мониторинг IMAP с настраиваемым интервалом 15–3600 секунд.
- Поиск ключевых слов выполняется **только в теле письма**, без учёта регистра. Если текстовой части нет, извлекается простой текст из HTML.
- Ключевые слова правила задаются через запятую. Правило считается подходящим, если совпали **не менее двух разных ключевых слов**.
- Если письмо подходит нескольким правилам, отправка выполняется **только по правилу с наибольшим числом совпадений**. При равенстве выбирается первое правило в порядке, возвращённом базой данных.
- Если ни одно правило не подошло, письмо остаётся непрочитанным.
- Разрешённые отправители: если список заполнен, правила проверяются только для писем от указанных адресов; если пуст — от всех отправителей. Исключения имеют приоритет.
- Исключённые отправители пропускаются и помечаются прочитанными.
- Telegram Bot API использует пул SOCKS5-прокси: загрузка, проверка, сортировка по скорости, кеширование и переключение при сетевой ошибке.
- MAX Bot API отправляет уведомления напрямую.
- Отдельная служба MAX принимает входящие события через Long Polling и отвечает на `/start`, `/help`, `/id`, `/status` и обычные сообщения.
- Журнал доставок и повторная обработка письма после ошибки доставки.
- Время в истории и на главной странице отображается по московскому часовому поясу (Europe/Moscow, UTC+3); временные метки в базе хранятся в UTC.

## Установка RC на новый сервер

Поддерживаемая платформа: **Ubuntu Server 24.04 LTS**, архитектура amd64. Нужен обычный пользователь с правами sudo и доступ в интернет.

### Вариант 1. Установка из GitHub

```bash
sudo apt update
sudo apt install -y git
git clone https://github.com/aptekashow/email-bridge-bot.git
cd email-bridge-bot
sudo bash install.sh
```

### Вариант 2. Установка из архива релиза

Скачай архив `email-bridge-bot-0.1.0-rc.2.tar.gz` со страницы Releases, распакуй его и запусти установщик:

```bash
tar -xzf email-bridge-bot-0.1.0-rc.1.tar.gz
cd email-bridge-bot-0.1.0-rc.2
sudo bash install.sh
```

Установщик:
1. Установит Python 3, venv, pip, CA-сертификаты и curl.
2. Установит приложение в `/opt/email-bridge-bot`.
3. Создаст виртуальное окружение и установит зависимости из `requirements.txt`.
4. При первой установке создаст `.env` со случайным секретным ключом и паролем администратора.
5. Настроит и включит три службы systemd: веб-панель, обработчик почты и MAX Bot Worker.

**Сразу сохрани пароль администратора**, который установщик выведет в терминал. Он не отображается повторно. При повторном запуске существующий `.env` не перезаписывается.

Панель: `http://IP_СЕРВЕРА:10000`.

Открой TCP-порт 10000 в firewall только для доверенных адресов. Для доступа через интернет настрой HTTPS reverse proxy.

## Первоначальная настройка

1. Открой панель и войди с паролем, выданным установщиком.
2. В настройках укажи IMAP-сервер, порт, логин и пароль почтового ящика.
3. Для Telegram создай бота через @BotFather и сохрани токен в настройках.
4. Открой диалог с Telegram-ботом и нажми Start. Добавь получателя в контакты и создай правило.
5. Для MAX укажи токен MAX, запусти диалог с ботом и отправь `/id`. Бот покажет User ID и Chat ID. Добавь MAX-контакт с получателем `user:USER_ID` (личный диалог) или `chat:CHAT_ID` (чат).
6. Создай правила. В каждом правиле укажи минимум два разных ключевых слова через запятую.
7. Отправь тестовое письмо и проверь историю доставок.

## Службы и диагностика

```bash
sudo systemctl status email-bridge-web email-bridge-worker email-bridge-max --no-pager
sudo journalctl -u email-bridge-web -n 100 --no-pager
sudo journalctl -u email-bridge-worker -n 100 --no-pager
sudo journalctl -u email-bridge-max -n 100 --no-pager
curl http://127.0.0.1:10000/health
```

Для просмотра логов в реальном времени используй `journalctl -u ИМЯ_СЛУЖБЫ -f`.

## Данные и безопасность

- Приложение и службы: `/opt/email-bridge-bot`.
- SQLite: `/opt/email-bridge-bot/email_bot.db`.
- Конфигурация и секреты: `/opt/email-bridge-bot/.env`, права доступа 0600.
- Маркер MAX Long Polling хранится в `.max_updates_marker`.
- Кеш SOCKS5-прокси: `proxies_cache.txt`.
- Не публикуй `.env`, базу данных, токены или пароли в GitHub.
- Публичные SOCKS5-прокси принадлежат третьим лицам. Они используются только для Telegram; не направляй через них IMAP, MAX или другие запросы с чувствительными данными.
- MAX Long Polling предназначен для текущей реализации и тестовой эксплуатации. Для production MAX рекомендует Webhook; Webhook и Long Polling нельзя использовать одновременно для одного бота.
