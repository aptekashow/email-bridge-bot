# Email Bridge Bot

Веб-панель и фоновый обработчик: проверяет почту по IMAP, ищет ключевые слова **только в теле письма** и пересылает совпадения в Telegram или MAX.

## Возможности

- Русскоязычная веб-панель: настройки, правила, история доставок.
- IMAP SSL, настраиваемый интервал проверки 15–3600 секунд.
- Создание, редактирование, включение и отключение правил пересылки.
- Несколько ключевых слов или фраз в одном правиле через запятую: достаточно совпадения любого одного слова (логика «ИЛИ»).
- Поиск ключевых слов без учёта регистра только в текстовом теле письма. Если текстовая часть отсутствует, извлекается простой текст из HTML.
- Отправка в Telegram Bot API через автоматически подобранный SOCKS5-прокси.
- Автоматическая загрузка публичного списка SOCKS5-прокси из `hookzof/socks5_list` каждые 2 часа.
- Проверка прокси реальным HTTPS-запросом к Telegram API, сортировка по времени ответа и выбор самого быстрого.
- Переключение на следующий прокси при сетевой ошибке.
- Кеш рабочего списка в `proxies_cache.txt`; он восстанавливается после перезапуска.
- MAX Bot API отправляется напрямую; SOCKS5 используется только для Telegram.
- Журнал доставок и повторная обработка писем, если доставка завершилась ошибкой.

## Установка на новый сервер (Ubuntu 24.04)

Подключись по SSH под обычным пользователем с правами sudo. Выполни:

```bash
sudo apt update
sudo apt install -y git
git clone https://github.com/aptekashow/email-bridge-bot.git
cd email-bridge-bot
sudo bash install.sh
```

Установщик:
- установит Python и необходимые системные пакеты;
- скопирует проект в `/opt/email-bridge-bot`;
- создаст виртуальное окружение и установит зависимости, включая поддержку SOCKS5;
- создаст защищённый `.env` со случайным паролем администратора при первой установке;
- создаст и запустит службы systemd для веб-панели и Worker.

**Сохрани пароль администратора, который установщик покажет при первой установке.** При повторном запуске существующий `.env` не перезаписывается.

Панель будет доступна по адресу `http://IP_СЕРВЕРА:10000`. Для прямого доступа открой TCP-порт 10000 в firewall только для доверенных адресов. Для публикации в интернете рекомендуется настроить HTTPS и ограничить доступ.

## Первоначальная настройка

1. Войди в панель по паролю, показанному установщиком.
2. В настройках укажи IMAP-сервер, порт, логин и пароль почты.
3. Для Telegram создай бота через @BotFather, получи токен и укажи его в настройках.
4. Открой диалог с ботом в Telegram и нажми Start.
5. Узнай числовой chat ID и добавь правило с каналом TG.
6. Добавь одно или несколько ключевых слов через запятую. Правило сработает, если хотя бы одно из них встретится в теле письма; тема не проверяется. Существующие правила можно редактировать.
7. Отправь тестовое письмо и проверь историю доставок.

Для MAX укажи токен MAX в настройках и добавь правило с каналом MAX. Получатель задаётся как `user:123`, `chat:123` или просто ID чата.

## Службы и логи

```bash
sudo systemctl status email-bridge-web email-bridge-worker
sudo journalctl -u email-bridge-worker -f
sudo journalctl -u email-bridge-web -f
```

Проверка веб-панели:

```bash
curl http://127.0.0.1:10000/health
```

## Секреты и данные

- Не добавляй `.env`, базу данных, токены или пароли в GitHub.
- `.env`, SQLite-база и кеш прокси исключены из Git.
- Сохраняй резервную копию `email_bot.db` и `.env` отдельно.
- Публичные SOCKS5-прокси принадлежат третьим лицам. Используй их только для Telegram Bot API. Не направляй через них IMAP, MAX или другие запросы с чувствительными данными.
- Публичный список может содержать нестабильные или недоверенные узлы. Проверяется только доступность Telegram API; содержимое сообщения всё равно проходит через выбранный сторонний прокси.
- Telegram Bot API напрямую с сервера может быть недоступен; если рабочие SOCKS5-прокси не найдены, Telegram-доставка будет повторяться при следующих циклах проверки почты.
- MAX отправляется напрямую и требует доступности `platform-api2.max.ru`.

## Ручная установка / разработка

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python app.py
```

В другом терминале:

```bash
source .venv/bin/activate
python mail_worker.py
```

Проверка синтаксиса:

```bash
.venv/bin/python -m compileall -q .
```
